# Personal Expense Tracker

## Course
IITK AIML Foundations – Programming Refresher

## Description

A Python-based personal expense tracker that allows users to record
daily expenses, categorize expenses, manage a monthly budget, and
save/load expense data using file handling.

## Features

- Add daily expenses
- Categorize expenses
- Set and track monthly budget
- Calculate spending
- Save expense data to a file
- Load previously saved expense data
- Menu-driven interface

## Technologies

- Python
- Jupyter Notebook
- Lists
- Dictionaries
- Functions
- File Handling
